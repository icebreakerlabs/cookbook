# Community skills

User-submitted skills. Each one is a folder here with a `SKILL.md`.

Open a PR to add one. Icebreaker-maintained skills stay in the parent [`skills/`](../) directory.

| Skill | What it does |
|-------|--------------|
| [`network-sync-report`](network-sync-report) | Read-only sync queue report for you or a team collaborator: offline HTML dashboard, shareable CSV, pagination and anomaly flags. |
